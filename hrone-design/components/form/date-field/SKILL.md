# DateField Component

## How to build this component

1. Read `../../../foundation/foundation-token/color.md` for semantic colors and field surfaces.
2. Read `../../../foundation/foundation-token/typography.md` for Noto Sans typography.
3. Read `../../../foundation/foundation-token/spacing.md` for label, field, and segment spacing.
4. Read `../../../foundation/foundation-token/radius.md` for field and segment corner radii.
5. Read `../../../foundation/foundation-token/effects.md` for field shadow and focus-ring behavior.
6. Use the relevant variant spec:
   - `variants/state-matrix/state-matrix.md`

## Available Variants

| Variant | Description |
|---|---|
| primary | White background with layered field shadow |
| secondary | Gray (#f1f1f1) background, field shadow omitted |
