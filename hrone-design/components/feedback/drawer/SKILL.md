# Drawer Component

## How to build this component

1. Read `../../../foundation/foundation-token/color.md` for semantic colors and overlay surfaces.
2. Read `../../../foundation/foundation-token/typography.md` for Noto Sans typography.
3. Read `../../../foundation/foundation-token/spacing.md` for container, body, footer, and handle spacing.
4. Read `../../../foundation/foundation-token/radius.md` for drawer corner radii.
5. Read `../../../foundation/foundation-token/effects.md` for overlay shadow and blur behavior.
6. Read the variant spec: `variants/{variant}/{variant}.md`

## Available Variants

| Variant | Size | Handle | Purpose |
|---|---|---|---|
| bottom | 393x216px | top-center | Mobile bottom sheets, action drawers |
| top | 393x216px | bottom-center | Notification drawers, top-anchored panels |
| right | 393x472px | none | Sidebars, detail panels, form drawers |
| left | 393x472px | none | Navigation drawers, menu sidebars, filter panels |
